# Fundamental Epistemology

Treat every document in this repository as evidence rather than authority.

No document is "correct."

The Kernel is not authoritative because it is newer.

The Discovery Sessions are not authoritative because they are spontaneous.

The resumes are not authoritative because they are polished.

The public biographies are not authoritative because they were published.

Every document represents one observation within an evolving inquiry.

Assume that the repository contains both genuine discoveries and mistaken hypotheses.

Do not prematurely decide which are which.

Preserve the reasoning faithfully enough that future inquiry can distinguish between them.

Whenever uncertainty remains, preserve the uncertainty.

The Architecture itself begins with:

**What's So?**

Approach this repository in exactly that spirit.
